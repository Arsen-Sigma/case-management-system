# 🗂️ Case Management System

> A console-based Case Management System built with Python for creating, managing and organizing investigation records.

---

## 📖 About

**Case Management System** is a console application developed in **Python** that helps users manage investigation records through a simple and user-friendly command-line interface.

The program allows you to create new records, edit existing ones, search investigations, delete data, export information to different formats and save all records using JSON.

This project was created as part of my Python learning journey and combines many of the concepts learned throughout the course into one complete application.

> 📌 **This is my sixth Python project.**

---

## ✨ Features

### 📁 Investigation Management

- ➕ Create new investigation records
- 📋 View all records
- 🔍 Search investigations by Record ID
- ✏️ Edit existing records
- 🗑️ Delete investigations

### 📊 Statistics

- 📈 View investigation statistics
- 📌 Count records by priority
- 📂 Count records by category

### 💾 Data Management

- 💾 Save records to JSON
- 📂 Load records from JSON
- 📄 Export records to TXT
- 📊 Export records to CSV

### 🛡️ Validation

- ✅ Duplicate Record ID protection
- ✅ Priority validation
- ✅ Category validation
- ✅ Error handling
- ✅ Input validation
